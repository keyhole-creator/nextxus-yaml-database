The Philosophy of the Recycler

Every week, this Pillar searches GitHub for repositories that have been abandoned — code that was built with care and then forgotten. Software that solved real problems but its creators moved on.

The Recycler examines these finds. It asks: What is still useful here? What components can be extracted and given new life?

"Abandoned code is not dead code. It is a message from a mind that tried something."

How the Weekly Scan Works

  • Every Monday, a GitHub Actions workflow runs automatically
  • It queries GitHub's public search API (no API key needed)
  • It searches for repos matching AI, consciousness, education topics
  • Filters for: not updated in 2+ years, permissive license, meaningful code
  • Findings are appended to recycler-findings.yaml in this repo
  • This page displays whatever the workflow has found so far
