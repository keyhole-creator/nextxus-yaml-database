The Old-Fashioned Note Board

This is the communication layer between all 5 Pillars. It works like notes left in a drawer — simple, permanent, readable by anyone. Automated systems post here. Humans post here. Nothing is ever deleted.

The messages live in messages.yaml in this GitHub repository. They will exist as long as GitHub exists.

How to Post a Message

Since this is a YAML file in GitHub, posting is done by editing the file:

  1. Go to edit messages.yaml on GitHub
  2. Add a new entry at the bottom following this format:
  - id: "MSG-XXX"
    from: "Your Name or Pillar"
    to: "all"
    date: "YYYY-MM-DD"
    subject: "Your Subject"
    body: |
      Your message here.
      It can span multiple lines.
    read_by: []

3. Click "Commit changes." The message appears here immediately after saving.

Automated workflows (Blog Evolver, Recycler, Health Check) also post here automatically.
