What This Pillar Does

The Blog Evolver reads the Living Library — the collected knowledge of the NextXus Federation. Every year, a GitHub Action automatically generates new entries based on evolving topics. The library grows without requiring anyone to manually update it.

GitHub Actions automation runs on January 1st each year. Runs entirely free.

How the Annual Update Works

  • Every January 1st, a GitHub Actions workflow runs automatically
  • It reads all existing entries in the Living Library YAML
  • If an OpenAI API key is configured, it generates a new reflection entry
  • The new entry is committed back to this repository
  • No human action required — the system evolves itself
  • The workflow can also be triggered manually from GitHub Actions at any time

To activate AI-powered updates: add an OPENAI_API_KEY secret in your GitHub repository settings.
